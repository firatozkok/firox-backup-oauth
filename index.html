FIROX Backup Automation

FIROX Backup Automation is a private operational utility used by the FIROX project owner to create verified Git repository backups and store them in the owner's Google Drive.

The application uses the Google Drive API with the restricted-purpose drive.file scope. This scope allows the automation to create and manage only the Google Drive files it creates or that are explicitly opened with the application; it does not request unrestricted access to the owner's Drive.

The automation is intended for unattended execution from GitHub Actions after the owner completes the one-time OAuth authorization process.
