Privacy Policy

FIROX Backup Automation is a private operational utility used by the FIROX project owner to back up a Git repository to the owner's Google Drive.

Google Drive access

The application requests the Google Drive drive.file OAuth scope. It does not request unrestricted access to all files in the user's Google Drive. The automation uses this access only to create, read back, verify, retain, and restore-test backup files that it creates or that are explicitly opened with the application.

Data processed

The application processes repository backup archives and related integrity metadata such as file names, timestamps, Git commit identifiers, file sizes, and checksums. OAuth credentials are used only to authorize the backup automation.

Storage and sharing

Backup files are stored in the project owner's Google Drive. Automation credentials are intended to be stored as encrypted GitHub repository secrets and are not published in source code or public documentation. The application does not sell user data or use Google Drive data for advertising.

Retention and deletion

Backup retention is controlled by the FIROX project owner. Backup files may be deleted as part of the project's documented retention policy or manually by the owner.

Third-party infrastructure

The automation relies on Google Drive and GitHub Actions. Those services may maintain their own operational logs and are governed by their respective privacy and security terms.

Contact

For questions about this utility, contact the project owner through the GitHub profile.
